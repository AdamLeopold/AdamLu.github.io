在你的电脑运行

连接本机 GPT-OSS

  1. 安装并打开 Ollama

    下载 Ollama ↗

  2. 在终端下载生成模型和检索模型
    ollama pull gpt-oss:20b
ollama pull nomic-embed-text

    模型保存在当前用户的 Ollama 模型目录，Ollama 会自动管理。

    模型信息与运行要求 ↗
启动这台电脑的建模工作台

下载运行包并解压，在解压后的文件夹中打开终端：

下载本机运行包 ↓
python3 scripts/run_demo.py --open

需要 Python 3.10+。Windows 可将 python3 改为 python。

OpenAI 使用你自己的 API Key，默认模型为 GPT-4.1。

工作台不持久保存 API Key；刷新页面后需重新输入。

Python 求解环境

模型产物与运行文件由本机工作台保存。运行生成的 Python 需要本机 Docker 和有效的 Gurobi 许可证；模型与代码可单独查看。

请在准备运行模型的电脑上打开工作台。手机上的本机地址指手机自身。
